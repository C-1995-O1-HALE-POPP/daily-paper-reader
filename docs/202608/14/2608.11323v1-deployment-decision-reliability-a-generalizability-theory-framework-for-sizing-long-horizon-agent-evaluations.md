## 摘要
企业实践者将智能体排行榜视为对智能体能力的排名。我们通过三个开放智能体轨迹基准（TheAgentCompany、$τ^2$-bench 和 AppWorld）证明，智能体主效应在每个数据集和检查类型中均占总方差不到3%，而智能体与任务交互效应占7-23%。排行榜排名衡量的是专长，而非能力。我们通过四侧面概化理论方差分解得出这一结论，使用三种估计器（Henderson Method-I、基于 lme4 的 REML 以及贝叶斯二项式 GLMM）拟合，结果一致到小数点后三位。另有四项进一步发现揭示了排行榜所隐藏的信息。首先，在难度最高的任务四分位上，聚合可靠性崩溃：$τ^2$ 上 action_checks 的 $Eρ^2$ 从0.752降至0.000。其次，训练单元可靠性与留出可靠性呈负相关（$τ^2$ 上 $r = -0.90$），这意味着表面最可靠的设计其复制效果最差。第三，总体层面的诊断指标可跨企业基准迁移（能力差距比稳定在0.35-0.40），但按家族划分的智能体排名会反转。第四，在 MAST 失败分类法上，轨迹层面的模式特征为特异性的（MAE = 0.261），而单元层面的模式特征具有泛化性（MAE = 0.056，$r = 0.83$）。我们将这些整合为部署决策可靠性（DDR），一种单页报告规范，将方差成分表转化为企业买家可以辩护的五项决策。所有代码、数据加载器和拟合产物均在开源许可下发布。

## Abstract
Enterprise practitioners read agent leaderboards as if they ranked agent capability. We show, across three open agent-trace benchmarks (TheAgentCompany, $τ^2$-bench, and AppWorld), that the agent main effect accounts for less than 3% of total variance in every dataset and check type, while the agent-by-task interaction accounts for 7-23%. Leaderboards rank specialization, not capability. We arrive at this through a four-facet Generalizability Theory variance decomposition, fit with three estimators (Henderson Method-I, REML via lme4, and a Bayesian binomial GLMM) that agree to three decimal places. Four further findings sharpen what the leaderboard is hiding. First, aggregate reliability collapses on the hardest task quartile: $Eρ^2$ on $τ^2$ action_checks falls from 0.752 to 0.000. Second, training-cell reliability negatively correlates with held-out reliability ($r = -0.90$ on $τ^2$), meaning the designs that look most reliable replicate worst. Third, population-level diagnostics transfer across enterprise benchmarks (capability-gap ratio stable at 0.35-0.40) but per-family agent rankings invert. Fourth, on the MAST failure taxonomy, trace-level mode profiles are idiosyncratic (MAE = 0.261) while cell-level profiles generalise (MAE = 0.056, $r = 0.83$). We package these into Deployment Decision Reliability (DDR), a one-page reporting discipline that turns the variance-component table into five decisions an enterprise buyer can defend. All code, data loaders, and fit artifacts are released under an open-source license.

## 论文总结：部署决策可靠性：用于长周期智能体评估规模化的概化理论框架

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：企业实践者通常将智能体排行榜上的分数直接解读为对智能体"能力"的排名，但一个压缩了多种测量方差来源的单一分数无法揭示榜单差距的真实来源——究竟来自智能体本身、任务组合、轨迹切割步骤、失败类别，还是这些因素的交互作用。
- **研究动机**：排行榜掩盖了智能体能力与任务特化之间的根本差异，导致企业部署决策缺乏可靠依据；同时，现有评估方法无法回答"生产环境评估需要多少任务才能复现基准差距"等实际部署问题。
- **整体含义**：论文将测量理论中的**概化理论（G-theory）**引入多步骤智能体评估场景，证明排行榜实际上衡量的是**专长（特殊化）**而非**统一能力（dominance）**，并提出"部署决策可靠性（DDR）"作为企业采购决策的可辩护报告规范。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

**（1）核心思想**
- 将每个观测值建模为四侧面完全交叉设计的二元成功指示变量，使用概化理论将总观测方差分解为信号成分（智能体主效应）和可解释噪声成分（任务、步骤、错误类别及其交互）。
- 通过**决策研究（D-study）**将方差成分转化为评估预算边界：达到目标概化系数所需的最小任务数、步数和判定者数量。

**（2）关键模型公式**
- 四侧面完全交叉G-study模型：

  `Y_atse = μ + νa + νt + νs + νe + νat + νas + νae + νts + νte + νse + ε_atse`

  其中每个ν项为零均值随机效应，方差为σ²·，ε为残差。**智能体（a）为测量对象**，因此σ²a是感兴趣的信号。

**（3）三种估计器（交叉验证）**
- **Henderson Method-I**：封闭式ANOVA估计器，可能返回负值，下限设为零。
- **REML（lme4）**：用于非平衡高斯随机效应模型的经典频率派估计器。
- **贝叶斯二项GLMM（bambi/numpyro）**：适用于二元结果的原理性估计器，报告后验中位数和95%可信区间。

**（4）可靠性系数**
- **概化系数Eρ²** = σ²a / (σ²a + σ²δ)，用于**相对排名决策**（σ²δ是相对误差方差）。
- **依从性系数Φ** = σ²a / (σ²a + σ²Δ)，用于**绝对阈值决策**（如SLA门槛，σ²Δ额外包含非智能体侧面的主效应）。

**（5）关键诊断指标**
- **能力上限分解**：能力差距比 = σ²a / (σ²a + σ²a:t)，度量智能体相关方差中主效应与交互效应的占比。
- **成本感知可靠性（RPD）**：RPD(a, B) = Eρ²(a, B) / C̄(a, B)，即每美元可靠性。
- **难度条件可靠性**：按任务平均成功率分为四分位，分别拟合每个分层内的G-study。
- **留出泛化测试**：50次随机70/30分割，比较训练单元投影的Eρ²与留出单元的经验Eρ²。

### 3. 实验设计：数据集、Benchmark 与对比方法

**（1）主要数据集**
| 数据集 | 规模与构成 |
|--------|-----------|
| **TheAgentCompany** | 175个企业任务（GitLab、OwnCloud、Plane、RocketChat），17个智能体×175个任务基础×1-3个检查点×{文本，图像}，共7783行 |
| **τ²-bench** | 客户服务工作流（航空、零售、电信），3个前沿智能体（Claude 3.7 Sonnet、GPT-4.1、o4-mini），4次重复/任务，50任务/领域；按5种检查类型分别拟合（db_check、action_checks、env_assertions、communicate_checks、nl_assertions） |

**（2）对比方法**
- 对比了三种方差成分估计器：Henderson Method-I、REML、贝叶斯二项GLMM（结果一致到小数点后3-4位）。

### 6. 论文的主要结论与发现

**发现一：能力上限（Capability ceiling）**
- 智能体主效应σ²a在每个数据集和检查类型中占总方差**不到3%**（在τ²的db_check和nl_assertions上恰好为零）。
- 智能体-任务交互σ²a:t占**7.5-12.5%**，比主效应大1-2个数量级。
- 能力差距比在TheAgentCompany上低于0.001，在τ²所有单元上低于0.19。

**发现二：困难任务崩塌（Hard-task collapse）**
- τ² action_checks的聚合Eρ²=0.752，但在最难任务四分位上崩至**0.000**。
- TheAgentCompany的聚合Eρ²=0.986，但Q4降至0.869。

**发现三：留出反转（Held-out reversal）**
- τ² action_checks上，训练单元投影与留出Eρ²的Pearson相关为**r=-0.90**（Spearman -0.91），留出值平均比投影低0.30。
- 训练单元投影系统性高估了复制研究能获得的可靠性。

**发现四：聚合与家族不对称（Aggregate vs. family asymmetry）**
- 能力差距比在TheAgentCompany（0.38）和AppWorld（0.35-0.40）间稳定可转移。
- 但按模型家族排名，TheAgentCompany与AppWorld之间的Spearman相关为**-0.50**（n=3，描述性）。
- 总体诊断可跨域迁移，但家族级排名不可移植。

**发现五：方差≠频率（Variance ≠ frequency）**
- τ²中σ²a:t按失败类别的分布与MAST失败激活率的相关为**-0.20**（n=4，描述性）。
- 方差成分与观测失败率是**正交诊断**——失败最多的类别并不等于智能体能力分化最大的类别。

**方法学结论**：将以上发现整合为**DDR（Deployment Decision Reliability）**报告规范，为企业买家提供五项可辩护的决策依据：任务采样数量、难度目标桶、成本约束带、留出协议要求和失败分类法读取方式。

### 7. 优点

- **方法论创新性**：首次将四侧面概化理论应用于多步骤智能体评估，将"评估设计是否支持部署决策"提升为一等测量设计问题。
- **多种估计器交叉验证**：三种估计器（Henderson、REML、贝叶斯二项GLMM）结果一致到小数点后3-4位，显著增强了结论可信度。
- **实践指导性强**：DDR框架提供单页报告规范，直接将方差成分转化为可辩护的采购决策，而非停留在理论层面。
- **诊断工具丰富**：难度条件可靠性、成本感知可靠性（RPD）、留出泛化测试等多维度诊断相互补充，为实践者提供了可操作的工具集。
- **诚实披露**：在限制部分明确交代了实验功效不足、手动分类映射等局限；附录中披露了AI辅助写作情况，所有数值均可复现。
- **代码开源**：所有代码、数据加载器和拟合产物均以开源许可发布，支持独立复现验证。

### 8. 不足与局限

- **功效不足的跨数据集比较**：TheAgentCompany与AppWorld的家族排名比较仅3个家族（n=3），τ²与MAST失败模式对比仅4个类别（n=4），统计功效有限，结论为描述性而非推断性。
- **步骤可交换性假设限制**：G-study将每个轨迹中的步骤视为可交换的。这对AppWorld单元测试和τ²奖励检查（任务内无序）适用，但对自由形式的轨迹分割不适用——步骤顺序会编码时序依赖。
- **能力上限是当前状态而非永久规律**：σ²a≈0的发现是"当前群体前沿智能体+现有测量设计"下的声明，不排除未来架构重新打开能力差距的可能性。
- **分类法映射缺少评级者间验证**：将14个MAST失败模式映射到四类分类法的手动分配未经过跨标注者有效性验证，作为固定分类可能掩盖新失败模式。
- **偏差风险**：训练单元与留出可靠性之间的负相关偏差（乐观估计偏差）是首次系统性展示，但缺少专门的小样本G-theory理论处理；受测设备和数据集的代表性也可能存在选择性。
- **应用限制**：DDR框架以排行榜整体为分析对象，对单一智能体供应商的内部一致性评估可能无法直接适用；成本数据的可靠性取决于定价来源的透明度。

### 其他说明

- 论文诚实说明了数据集选择从原预分析计划（AndroidWorld、OdysseyBench）因无公开步骤级轨迹数据而替换为TheAgentCompany和τ²-bench的过程，并说明替换标准全部满足原计划规定。
