## 摘要
机械通气是一种关键的生命支持干预措施，随着患者病情的变化，需要对呼吸机设置进行动态调整。虽然强化学习（RL）为优化这些序贯决策提供了一个有前景的框架，但标准方法主要依赖于结构化电子健康记录（EHR）数据，遗漏了记录在自由文本笔记中的关键临床背景信息。将纵向临床笔记整合到强化学习状态空间中具有挑战性，因为笔记被时间性冗余严重膨胀，例如复制转发文本、模板化和重复记录，这会稀释时间局部更新并降低状态表示质量。为了解决这个问题，我们提出了一种冗余感知的多模态状态表示框架，该框架在策略学习之前显式地去除随时间重复的笔记文本。我们评估了两种计算高效的时间分解策略来去除重复笔记文本：（1）基于局部历史子空间奇异值分解的嵌入空间分解；（2）一种可解释的句子级差异操作，在文本编码前过滤掉先前已记录的句子。利用真实世界ICU数据，我们证明，通过去除时间性笔记冗余构建的状态表示在多种离线策略评估方法（基于模型的推演、拟合Q评估、加权重要性采样和加权双稳健评估）中显著优于仅结构化数据和原始笔记的基线。我们的研究结果表明，从重复的笔记文本中显式分离出新的临床信息可以产生更高质量的状态表示，并直接提升强化学习在临床决策支持中的性能。

## Abstract
Mechanical ventilation is a critical life-support intervention, requiring dynamic adjustments to ventilator settings as a patient's condition evolves. While reinforcement learning (RL) offers a promising framework for optimizing these sequential decisions, standard approaches rely primarily on structured electronic health record (EHR) data, missing crucial clinical context recorded in free-text notes. Integrating longitudinal clinical notes into RL state spaces is challenging because notes are heavily inflated by temporal redundancy, such as copy-forward text, templating, and repetitive documentation, which dilutes time-local updates and degrades state representation quality. To address this, we propose a redundancy-aware multimodal state representation framework that explicitly removes duplicated note text over time before policy learning. We evaluate two computationally efficient temporal decomposition strategies for removing duplicated note text: (1) an embedding-space decomposition using singular value decomposition on local history subspaces, and (2) an interpretable sentence-level diff operation that filters out previously documented sentences before text encoding. Using real-world ICU data, we demonstrate that state representations constructed by stripping temporal note redundancy significantly outperform both structured-only and raw-note baselines across multiple off-policy evaluation methods (Model-Based Rollouts, Fitted Q-Evaluation, Weighted Importance Sampling, and Weighted Doubly Robust Evaluation). Our findings show that explicitly isolating new clinical information from repeated note text yields higher-quality state representations and directly improves RL performance for clinical decision support.

## 1. 核心问题与整体含义

- **研究背景**：机械通气是重症监护中维持呼吸功能的关键干预，需要随患者病情动态调整呼吸机参数。强化学习（RL）可用于学习最优序贯治疗策略，但现有方法主要使用结构化 EHR 数据，忽略了蕴含丰富临床背景的自由文本笔记。
- **核心问题**：临床笔记存在严重的时间性冗余（复制转发、模板化、重复记录），如果直接将原始笔记嵌入作为 RL 状态，会使得“长期不变的背景信息”淹没“新出现的临床变化”，从而降低状态表示质量，影响策略学习与评估。
- **论文含义**：提出一种“冗余感知”的多模态状态表示框架，在策略学习前显式地将笔记分解为“历史成分”和“新信息成分”，从而让 RL 能够更准确地捕捉与当前决策相关的临床变化。实证表明该方法显著优于仅结构化数据和原始笔记拼接的基线。

## 2. 方法论

### 核心思想
- 将临床笔记视为“历史背景 + 当前更新”的组合：从时间冗余中剥离出新信息，再与结构化变量融合构成 RL 状态。
- 提出两种互补、计算高效的时序分解方法，均不依赖昂贵的 LLM 逐次处理。

### 方法一：嵌入空间 SVD 时间分解
- 流程：在笔记嵌入之后进行去冗余。
  - 对于时间步 \(t\)，取当前笔记嵌入 \(x_t\) 和过去 \(k\) 条笔记嵌入 \(x_{t-k},...,x_{t-1}\)。
  - 计算历史均值 \(\mu_t^{\text{hist}}\)，构建中心化历史矩阵 \(H_t \in \mathbb{R}^{k \times d_n}\)。
  - 对 \(H_t\) 做 SVD：\(H_t = U_t \Sigma_t V_t^\top\)，取前 \(\ell\) 个右奇异向量构成历史子空间 \(V_{t,\ell}\)。
  - 计算当前向量 \(y_t = x_t - \mu_t^{\text{hist}}\) 在历史子空间上的投影：
    - 历史分量：\(x_t^{\text{svd,hist}} = \mu_t^{\text{hist}} + V_{t,\ell} V_{t,\ell}^\top y_t\)
    - 新信息分量：\(x_t^{\text{svd,new}} = (I - V_{t,\ell} V_{t,\ell}^\top) y_t\)
  - 于是 \(x_t = x_t^{\text{svd,hist}} + x_t^{\text{svd,new}}\)，实现了加性分解。

### 方法二：句子级 Diff 分解
- 流程：在文本编码之前进行去冗余。
  - 将当前笔记切分为句子序列 \(S_t\)，将最近 \(k\) 条笔记的句子序列拼接为历史句子集 \(R_t\)。
  - 使用基于最长公共子序列的经典 diff 算法（Hunt-McIlroy）比较 \(S_t\) 与 \(R_t\)，得到：
    - 历史句集合 \(S_t^{\text{hist}}\)（与历史重复的句子）
    - 新句集合 \(S_t^{\text{new}}\)（新增的句子）
  - 分别拼接成文本 \(D_t^{\text{hist}}\) 和 \(D_t^{\text{new}}\)，再分别用 ClinicalBERT 编码得到 \(x_t^{\text{diff,hist}}\) 和 \(x_t^{\text{diff,new}}\)。

### 状态构建与 RL 学习
- 对各笔记分量用 PCA 压缩到 64 维（在训练集上拟合），与结构化变量拼接形成最终状态：
  - 结构化 only：\(s_t^{\text{struct}} = u_t\)
  - 原始笔记：\(s_t^{\text{raw}} = [u_t, z_t^{\text{raw}}]\)
  - SVD 冗余感知：\(s_t^{\text{svd}} = [u_t, z_t^{\text{svd,hist}}, z_t^{\text{svd,new}}]\)
  - Diff 冗余感知：\(s_t^{\text{diff}} = [u_t, z_t^{\text{diff,hist}}, z_t^{\text{diff,new}}]\)
- 策略学习：
  - 行为克隆（BC）用于估计行为策略和作为模仿基线。
  - 保守 Q 学习（CQL）作为主要离线 RL 算法，使用相同的超参数和训练流程，仅状态表示不同。
- MDP 设置：4 小时决策间隔，动作空间包含潮气量、PEEP、FiO₂ 的离散组合，奖励函数鼓励 SpO₂ 改善并惩罚过高通气强度。

## 3. 实验设计

### 数据集与场景

- 规模：10,125 次 ICU 停留，157,924 条临床笔记，对齐到 147,997 个 4 小时决策间隔。
- 预处理：沿用 Lee et al. (2025) 的队列构建与结构化数据预处理流程，截断至前 72 小时通气（最多 18 个决策点）。
- 划分：80/20 训练/测试划分，训练集内 5 折交叉验证调参（使用结构化 only 表示选择共享的超参数）。

- 结构化 + 原始笔记（多模态基线）

- 结构化 + 句子级 diff 冗余感知笔记（本文方法 2）

## 6. 主要结论与发现

- 冗余感知状态表示在四种 OPE 下均显著优于结构化 only 基线：
  - SVD 表示提升：FQE +0.12，WIS +0.40，WDR +0.22，MB +0.73。
  - Diff 表示提升更大：FQE +0.27，WIS +0.64，WDR +0.41，MB +0.75。
- 冗余感知表示同样优于原始笔记基线，而原始笔记相对于结构化 only 没有一致改善（多数置信区间包含 0）。
- 句子级 diff 方法整体优于嵌入空间 SVD 方法，说明在文本层面显式去除重复句更符合复制转发式冗余的特点。
- 案例研究表明：当笔记中包含大量与通气无关的新信息（如手术计划、输血、电解质异常）但通气状态本身稳定时，原始笔记表示会使策略改变动作；冗余感知表示则能保留稳定通气历史，继续推荐与临床一致的动作。

## 7. 优点

- **问题切入角度新颖**：首次系统研究“临床笔记时间冗余”对离线 RL 状态表示的影响，并提出专门解决方案。
- **计算高效**：不依赖重复调用大语言模型，使用 SVD 和文本 diff 即可实现去冗余，适合大规模 ICU 轨迹。
