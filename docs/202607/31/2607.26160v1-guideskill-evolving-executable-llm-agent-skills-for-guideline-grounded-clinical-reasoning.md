## 摘要
临床实践指南（CPGs）编码了诊断标准，但大语言模型系统通常检索指南文本或通过训练吸收指南内容，而非执行其规则。我们提出GuideSkill，一种外部推理层，将疾病特异性标准编译为返回序数诊断支持分数的可执行函数。GuideSkill-Zero从指南初始化，而GuideSkill-Evo利用病例-诊断配对来细化已覆盖的技能并添加缺失的诊断。在推理时，大语言模型提出鉴别诊断，确定每个匹配技能所需特征的依据，并将其排序与执行的技能分数融合。在四个基准和四个主干模型上，GuideSkill-Zero相比指南RAG平均将宏平均准确率提高13.45%。GuideSkill-Evo在每个主干模型上均达到最高宏平均，相对直接推理提高18.49%，并将黄金标签技能覆盖率从56.5%提升至99.5%。在Qwen3.5-9B上，它还在不更新主干模型的情况下超越最强参数更新基线11.16%。专家评估进一步表明，GuideSkill产生临床合理且广泛可接受的技能，表明其初始化和进化的规则可靠且具有实际意义。这些结果支持可执行技能作为将指南衍生程序与病例衍生诊断模式相结合的模型无关机制。

## Abstract
Clinical practice guidelines (CPGs) encode diagnostic criteria, but LLM systems typically retrieve guideline text or absorb it through training rather than execute its rules. We introduce GuideSkill, an external reasoning layer that compiles disease-specific criteria into executable functions returning ordinal diagnostic-support scores. GuideSkill-Zero is initialized from guidelines, while GuideSkill-Evo uses case--diagnosis pairs to refine covered skills and add missing diagnoses. At inference, an LLM proposes a differential diagnosis, grounds the features required by each matched skill, and fuses its ranking with the executed skill scores. Across four benchmarks and four backbones, GuideSkill-Zero improves macro-average accuracy over guideline RAG by 13.45% on average. GuideSkill-Evo achieves the highest macro-average for every backbone, improves over direct inference by 18.49% relatively, and increases gold-label skill coverage from 56.5% to 99.5%. On Qwen3.5-9B, it also exceeds the strongest parameter-update baseline by 11.16% without updating the backbone. Expert evaluation further indicates that GuideSkill produces clinically sound and broadly acceptable skills, suggesting that its initialized and evolved rules are reliable and practically meaningful. These results support executable skills as a model-agnostic mechanism for combining guideline-derived procedures with case-derived diagnostic patterns.

### 1. 核心问题与研究动机

- **核心问题**：临床实践指南（CPGs）编码了循证的诊断标准与条件决策逻辑，但现有 LLM 系统在利用指南时存在根本性缺陷——它们要么通过检索将指南文本拼接到提示中，期望 LLM 自行解释和应用；要么通过训练将指南内容吸收进模型参数。这两种方式都无法保证 LLM 真正"执行"指南中的规则：即使提供了指南检查清单，LLM 在判据级别上的遵循仍然不完美，可能遗漏临床推理证据或偏离诊断指南。
- **关键追问**：能否将 CPGs 从被动参考文本转化为一个**可进化的可执行诊断技能库**——既保留 LLM 灵活开放的候选生成能力，又能对每个候选诊断显式应用疾病特异性规则？
- **研究缺口**：既有工作（指南 RAG、指南微调、决策树等）均受限于初始指南语料——对语料未覆盖的诊断无计可施，也缺乏从标注病例中学习新诊断模式的能力。GuideSkill 旨在填补这一空白。

### 2. 方法论：核心思想与技术细节

#### 总体框架
GuideSkill 将 CPGs 从被动参考转化为**外部、疾病索引、可执行**的技能库，包含三个阶段：技能初始化（GuideSkill-Zero）、技能进化（GuideSkill-Evo）、技能执行（推理）。整个框架不更新 LLM 参数，知识以外部 Python 函数形式存储和演进。

#### 任务形式化
- 输入：未诊断患者病例 x（含人口学、主诉、病史、体格检查、检验结果）；输出：最终诊断 d⋆ ∈ D。
- 诊断空间标准化为三位字符 WHO ICD-10 类别。
- 推理时 LLM 先生成排序的鉴别诊断集合 C(x) = {d₁,…,d_K}（默认 K=5）。
- LLM 排序分数：s_LLM(x,d) = 1/(rank_d+1)；技能证据分数：s_skill(x,d) = g_d(x)。
- 融合分数：S(x,d) = α·s_LLM(x,d) + (1−α)·s_skill(x,d)，默认 α=0.5；取最高分者作为最终预测。

#### 技能初始化（GuideSkill-Zero）
- 从 37,970 份原始指南文档出发，经**四阶段级联过滤**：来源过滤（仅保留 NICE、PubMed、CMA、CDC、SPOR、WHO、CCO 七个权威来源）、长度过滤、LLM-as-judge 可用性过滤（判断是否含可操作临床指导）、长度异常值截断，最终得到 3,938 份高质量指南。
- 用 Claude-Opus-4.8 提取**原子诊断推荐**（发现/证据 → 疾病结论的规则），严格约束为疾病级结论且可映射到三位 ICD-10 类别，得到 1,200 条推荐、覆盖 349 个 ICD-10 疾病类别。
- 按疾病合并推荐后，用 LLM 将每条合并陈述编译为**可执行 Python 函数**——每个技能接受患者特征字典，输出 0–3 四个支持层级（Confirmed / Strongly Suggestive / Compatible / Not Supported），归一化为 [0,1] 分数；矛盾证据可降级。

#### 技能进化（GuideSkill-Evo）
- 输入：标注病例训练集 T = {(x_j, d_j)}。
- **Rationale 生成**：LLM 为每个病例生成支持其黄金诊断的推理摘要。
- **病例到推荐蒸馏**：按 ICD-10 分组，将反复出现的诊断标准蒸馏为疾病级规则；已有对应指南推荐时以其为骨架且**永不削弱**。
- **技能更新逻辑**：
  - 已有技能 → 用 ΔR_d 优化（Optimize）；
  - 无技能 → 用 ΔR_d 生成新技能（Generate）。
- 进化后技能库从 349 个类别扩展到 473 个（新增 267 个，共享 206 个），黄金标签覆盖率从 56.5% 提升至 99.5%。

#### 推理时的技能执行
- LLM 生成 Top-K 鉴别诊断 → 按疾病名或 ICD-10 代码检索匹配技能 → LLM 按技能文档字符串提取所需患者特征（特征接地）→ 执行技能获得证据分数 → 与 LLM 排序分数融合取最大。

### 6. 主要结论与发现

1. **指南初始化即有显著增益**：GuideSkill-Zero 在每个主干上均优于指南 RAG，平均宏准确率提升 13.45 个百分点，表明"执行指南规则"优于"检索指南文本"。
2. **进化带来持续提升**：GuideSkill-Evo 在所有 16 个数据集-骨干比较中优于直接推理，平均相对提升 18.49%。
3. **技能覆盖率大幅提升**：黄金标签技能覆盖率从 GuideSkill-Zero 的 56.5% 提升至 99.5%，技能库从 349 个类别扩展至 473 个。
4. **跨基准迁移有效**：MedThink-Bench（未参与进化）上 GuideSkill-Evo 在所有四个骨干上均优于 GuideSkill-Zero，且大幅超过参数更新基线（34.55 vs. 21.82），表明病例衍生更新可泛化到未见基准。
5. **不更新参数优于参数更新**：Qwen3.5-9B 上 GuideSkill-Evo（50.98）超越最强参数更新基线（45.86）5.12 个百分点，超越指南决策树基线 16.26 个百分点。
6. **可执行技能比文本技能更稳定**：相同候选集下平均准确率相当（60.94 vs. 60.60），但可执行技能在 5 次运行中零方差，提供可重复的评分接口。
7. **临床有效性初步确认**：95.2% 的初始规则与指南一致；85% 的进化病例被医生认为适合技能进化；86.3% 的技能输出与医生盲评在 1 层以内一致（加权 κ=0.60）；9/10 最终技能被接受（无需修改或仅需微调）。

### 7. 优点

- **范式创新**：将 CPGs 从被动文本转化为外部可执行技能库，实现了"模型无关"的诊断知识维护——技能库可跨主干复用、可在不触碰模型参数的情况下更新和审查。
- **双层知识互补**：LLM 负责开放式的候选生成（保持对库外诊断的覆盖），技能库负责显式的判据执行。融合机制（α=0.5 的简单设置）在四个基准上均稳健，且分析表明纯 LLM 排序或纯技能评分均非普遍最优。
- **进化机制的精心设计**：病例蒸馏时以现有指南推荐为骨架且"永不削弱"，并对病例进行分组 map-reduce 式分批归纳以防遗忘；新技能和已有技能采用不同的更新路径。
- **质量控制出色**：指南语料经过四阶段级联过滤（37,970 → 3,938 篇）；推荐提取施加严格的可执行性约束；技能按统一 0–3 层契约编码，保证了跨疾病可比性。
- **实验严谨性**：训练基线与 GuideSkill 使用相同骨干、数据分割和评估协议；临床医生评估采用分阶段盲法（先盲评留出病例再揭晓技能），有效减少锚定偏差；错误分析揭示主要失败模式是候选召回而非技能评分。
- **效率意识**：提出 GuideSkill-Effi 变体，将每次病例的 LLM 调用从 1+N 降为 2，MedCaseReasoning 上成本降低 72.7%，准确率仅降 0.34 点，实现更好的准确率-成本平衡。

### 8. 不足与局限

- **指南覆盖有限**：当前技能库仅基于 3,938 份精选指南，许多高质量指南尚未纳入，限制了初始库的广度和可靠性。
- **完全自动化的质量风险**：技能初始化和进化均为全自动 LLM 流程，虽有临床医生事后评估，但医生未深度参与生成过程的验证；临床评估也只覆盖 10 个技能（规模较小，且仅 1 位临床医生）。
- **错误分析揭示的瓶颈**：60.9% 的错误源于黄金 ICD-10 类别不在候选集中（候选召回失败），其中 74.8% 是编码粒度问题（LLM 提出临床相关但非精确 ICD-10 类别的诊断）——技能执行无法补救召回失败。
- **评估裁判偏差风险**：使用 LLM-as-judge 进行语义匹配，存在系统性偏差和推理局限；精确 ICD-10 类别匹配作为主要标准可能低估临床合理的近似诊断。
- **融合参数和候选大小未按基准调优**：默认 α=0.5 和 K=5 在不同基准上非最优（如 MedThink-Bench 最优 α=0，MIMIC 最优 α=0.35），说明不同任务对 LLM 排序与技能分数的信任度不同。
- **进化可能引入负迁移**：临床评估中发现一个案例——进化病例将原本正确的规则过度泛化为不适当规则；图 3 也显示已覆盖类别上有 5/16 个骨干-基准组合出现准确率下降（最多 −3.6 点）。
- **效率与成本**：原始 GuideSkill 的推理成本较高（每万例 409.01 美元），显著高于基线方法（CoT 201.41 美元、RAG 145.49 美元），虽有效变体降低成本，但默认版本的部署成本仍是实际障碍。
- **应用场景限制**：论文自认为研究原型而非可直接临床部署的系统，需要更广泛的临床验证（更大量医生、多中心评估）后才能实际使用。
